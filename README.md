House Price Prediction Using Linear Regression



Project Overview



This project uses Linear Regression to predict house prices from housing-related features. It demonstrates a basic machine learning workflow, from exploratory data analysis to model evaluation.



Objectives



Explore and understand the dataset.



Investigate missing values, duplicates, outliers, and multicollinearity.



Train a Linear Regression model.



Evaluate predictions using MAE, RMSE, and R².



Explore hyperparameter selection using GridSearchCV.



Technologies Used



Python



Pandas and NumPy



Matplotlib and Seaborn



Scikit-learn



Jupyter Notebook



Model Evaluation



The model is evaluated using:



Mean Absolute Error (MAE)



Root Mean Squared Error (RMSE)



R² Score



Project Files



house\_price\_prediction.ipynb — analysis, model training, and evaluation.



house\_price\_regression\_dataset.csv — dataset used for training and testing, if redistribution is permitted.



How to Run



Clone this repository.



Install the required Python libraries.



Open the notebook in Jupyter Notebook or Google Colab.



Run the cells in order.
